## Avant de commencer 
- Clone le  repository via clone
- creer une branch via la commande  `git checkout -b <votre_nom/votre_prenom>`
- initialisez votre branche en amont via la commande `git push -u origin <votre_nom/votre_prenom>`
- Rajouter vos fichiers locaux 

## Roadmap
La feuille de route attendu est d'évoluer le projet suivant les differents TP abordés en cours.

A la fin de chaque TP , vous devez :
- Committer vos changements avec un message clair. Exemple de message de commit : `git commit -m "TP : Ajout de la fonctionnalité X"`
- Pusher vos changements sur votre branche distante
